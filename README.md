# Финансовая система fashion-бренда

Демо-кейс для отклика на позицию финансового директора в fashion/e-commerce бренде.

## Что внутри
- панель финансового директора
- ОПиУ по каналам
- ДДС на 13 недель
- управленческий баланс и оборотный капитал
- запасы и рентабельность запасов
- экономика магазинов
- производство и закупки
- контроль качества данных

## Публикация на GitHub Pages
1. Загрузите файл `index.html` в корень публичного репозитория.
2. В `Settings -> Pages` выберите `Deploy from a branch`.
3. Укажите ветку `main` и папку `/(root)`.
4. Сохраните изменения и дождитесь публикации.
